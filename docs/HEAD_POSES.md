# 顔を9方向の配置で動かす

通常再生は **体・髪の揺れ＋瞬き＋ランダムな顔向き**。急に飛ばず、少し止まってから次の向きへ移動する。ランダムと円運動は切替式で、方向ボタンや手動スライダーを動かすと自動顔向きは止まる。速度・動きの強さ・一時停止は顔にも反映する。`head_pose.autoplay: false` をプランに指定するとランダム再生を初期OFFにできる。

## 使い方

1. 「左上・上・右上／左・正面・右／左下・下・右下」から保存する方向を選ぶ。
2. 「選択した方向の配置を編集」をONにする。動きと瞬きを止め、開いた目・口で編集する。
3. 顔・白目・黒目・髪などを選び、左右上下の位置、縦横の大きさ、傾きを調整する。
4. 顔の点を直接ドラッグするか、頂点を選択して数値スライダーで輪郭・頬を調整する。折り返す動きは拒否する。
5. 「この配置を保存」でブラウザ内へ保存する。方向を切り替えた未保存の調整もセッション内には残る。再読み込み前に保存する。
6. 9方向を調整して「顔をぐるぐる動かす」でつながりを見る。顔の左右・上下スライダーでも中間の角度を選べる。
7. JSONに書き出してバックアップする。別ブラウザではファイル選択から読み込む。

「初期値」は再生・目・口・視線の操作を戻し、保存済みの顔配置は維持する。ブラウザのデータ削除・プライベートブラウズ・別オリジンでは保存の扱いが異なるため、仕上げた配置はJSONも保存する。

## パーツ分割

```json
{
  "id": "eye_left_white",
  "source": "normal",
  "mask": "work/masks/eye_left_white.png",
  "role": "eye",
  "kind": "eye_sclera",
  "iris_part": "eye_left_iris",
  "closed_part": "eye_left_closed",
  "mesh": {"type": "blink_eye_radial"},
  "head": true
}
```

黒目は`kind: eye_iris`と`clip_to: eye_left_white`。まつ毛は任意で`kind: eye_line`と同じ`clip_to`を使う。左右は独立した組を作る。白目マスクには黒目の下の領域も含める。元の黒目が固定で残らないよう、その領域だけ白目色で下塗りした派生レイヤーを作る。白目色は明るい可視部分から取得し、不十分なら`sclera_fill: [R,G,B]`を指定する。まつ毛は白目の外側にも描けるが、黒目は変形後の白目αで必ず切り抜く。

顔の肌は`role: face`、`mesh.type: face_grid`にする。顔の下地に目や口を残さない。顔につながる髪などは`head: true`、胴などは`head: false`。閉眼・閉口は対応する開眼・開口の配置に追従し、必要なら方向ごとに個別調整もできる。

## データと補間

`head_pose.poses`のキーは`center, left, right, up, down, up_left, up_right, down_left, down_right`。

各方向の`parts[part_id]`に`x, y, rotation, scale_x, scale_y, vertices`を保存する。位置と頂点の差分はキャンバスのピクセル単位、回転は度、倍率は1が元のサイズ。頂点は左上から行優先で、4×4分割なら25点。各頂点の`[dx,dy]`で顔・パーツの形を変える。

向きはX/Yともに-1..1（画面左=-1、上=-1）。近い4つの保存配置を重みづけして補間する。9方向の端点では保存値を正確に再現する。目の開閉変形→方向別メッシュ→パーツのモーション→黒目の白目クリップの順に描画する。

ブラウザ保存とJSON読込ではパーツ配置・画像・メッシュ分割数の署名を確認する。異なるキャラの配置は受け付けない。再生成に反映するには`toolbox/import_head_poses.py`でプランへ戻す。

最初に自動で入るのは控えめな提案配置で、最適化済みの完成形ではない。横顔や後頭部など、元絵に見えていない部位を出すには追加の作画が必要。
