# ChibiRigKit ブラウザプレイヤー

ChibiRigKitだけで、保存済みキャラの表示・編集、カメラと音声の追従、モーション録画と再生を行います。

## 起動

Node.js 22以上を使用します。ChibiRigKitフォルダで初回に `npm run player:setup`、以後は `npm run player` を実行し、表示されたlocalhost URLをブラウザで開きます。既定は `characters/milkc0de`。別のキャラは `npm run player -- --character characters/<キャラ名>` で指定します。

サーバーは指定した `rig.project.json` を最新の共通ランタイムで表示します。キャラの再生成やファイルの読み込み直しは不要です。カメラ・マイクは開始ボタンを押すまで利用しません。Electron、デスクトップポップアップ、仮想カメラ、配信、プレイヤーHTML／ZIPの取り込み機能はありません。

## カメラ・音声とモーション

MediaPipeはローカルのWorkerで顔を追跡し、マイク音量は口パクに変換します。独自ChibiRigMotion v1の録画・保存・再生に対応し、生映像や生音声はモーションファイルに保存しません。モーションのヨー／ピッチ／ロール倍率はそれぞれ0〜3倍で変更できます。

追従の準備中・追従中は「入力・カメラ・マイク」の3セレクトをロックします。停止・開始失敗で解除します。「目・視線の追従をオフ」「口の追従をオフ」「頭の追従をオフ」で表示に使う入力を選べます。カメラ使用中も頭のスイッチは操作できます。マイクだけの口パクでは口のオフは操作できません。

オフの部位は、再生中のモーションファイル、通常の動きの順で表示します。一時停止・再生終了したファイルは追従中の代替入力には使いません。カメラとモーション再生は併用できます。チェックは表示入力の選択で、デバイス停止は「入力を停止」、モーション録画は入力データの記録です。

WebM動画はドラッグで指定した範囲を1280×720で保存します。四隅でサイズ変更、内側で移動、Shift＋ドラッグで新しい範囲を指定します。

## 完成品と制作契約

完成品HTMLのタブのタイトルは「キャラクター名 - ChibiRigKit」です。完成品は `dist/<キャラ名>/index.html`、ZIPは `dist/<キャラ名>.zip`。どちらもGit対象外です。Web画面の「完成品をdistに保存」、または `npm run export -- --character characters/<キャラ名>` を使います。出力フォルダとZIPには `index.html`、`LICENSE.txt` と、`START_SERVER.ps1`・`.cmd`・`.command`・`.sh` の4種類の起動ファイル、`PLAYER_SERVER.py` に加えて、`runtime/tracking_worker.js`、`vendor/mediapipe/` の追跡SDK・WASM・顔モデル、`licenses/` のライセンス表記を含めます。画像・設定・選択した録画モーションはHTML内に保存し、外部の `assets/` やJSONは同梱しません。制作データは元のキャラフォルダに残します。HTML単体はブラウザで再生できます。カメラ収録はローカルサーバーから行います。

`template/workspace/runtime/` が共通実装、`studio/` がChibiRigKitのローカルサーバーです。Codex制作契約は `rig.workflow.json`、説明は `AUTO_RIG_TASK.md`。`scripts/update-character.py --character <folder>` は古い実装をバックアップして更新します。画像やリグは再構築しません。

新規制作はヨー・ピッチ -25/0/+25度の9方向で整え、上下の変形は約50%から調整します。見かけの大きさ、遠い目と髪・輪郭との余白、口と顎の方向、首の接続を優先します。既存の別角度のメッシュは勝手に再解釈しません。

`neck_fill` は補完用の派生画像、`skin_rect`、`head_edge`、`body_edge`、`body_part` をキャラ側に指定します。長い髪は `physics: {type: "long_hair", stiffness: 16, damping: 7}` を使用できます。左右を明示する場合は `capture_side: "left"` または `"right"`（画面上の左右）を使用します。サンプル固有の座標を他キャラへ流用しません。

元画像は保持します。オリジナルコードはApache-2.0です。依存ライブラリに付属するライセンス表記は保持します。 MediaPipe Tasks Vision 1.0.1・WASM・顔モデルはApache-2.0です。完成品の `licenses/mediapipe-LICENSE.txt` と `licenses/mediapipe-NOTICES.txt` に原文・配布元・著作権を記載します。`TRACKING_DOWNLOADS.json` にも配布元・ハッシュ・ライセンスを記録し、ChibiRigKit本体のApache-2.0とは別の配布物としてライセンス表記を保持します。セットアップ時にSDKとモデルのハッシュを `tracking-dependencies.json` に保存します。

完成品の `dist/<キャラ名>/index.html` 自体がプレイヤーです。別のプレイヤーアプリへ取り込む手順はありません。そのままブラウザで再生・調整・モーション読込ができます。カメラ・音声追従は完成品ZIPをすべて展開して `START_SERVER` で起動し、操作用URLで利用します。ChibiRigKitでは指定キャラを `npm run player` で開く方法も使えます。

## プライバシーとオフライン利用

完成品の再生・調整・WebM保存にインターネット接続は不要です。SDKとモデルを準備済みなら、カメラ・マイクもローカル起動でオフライン利用できます。初回のセットアップとCodexによる制作には接続が必要で、制作時の画像と指示はCodexへ渡します。

完成品へ機器名・デバイスID・元の背景ファイル名を保存しません。選択中の背景画像は含みます。録画モーションは同梱チェックをオンにした場合だけ含み、日時や付加メタデータは除きます。WebM録画中も「入力を停止」を使え、その場合は録画を中止し動画を保存しません。

## 完成品のローカルサーバー

Python 3を利用し、追加パッケージは不要です。ZIPを展開し、Windowsは `START_SERVER.cmd`（PowerShellなら `./START_SERVER.ps1`）、Macは `START_SERVER.command`、Linuxは `sh START_SERVER.sh` で起動します。利用可能なPython 3を自動判別します。PowerShellの実行ポリシーで止まる場合は `.cmd` を使用できます。

**このPCの中だけで動く表示・共有用サーバーです。インターネットには公開されず、同じWi-Fiの別の端末からもアクセスできません。起動・表示にインターネット接続は不要です（Python 3の導入時を除く）。**

ブラウザで操作するURLは `http://127.0.0.1:5510/` です。OBSの「ブラウザ」ソースでは「ローカルファイル」をオフにし、表示専用URL `http://127.0.0.1:5510/obs` を指定します。OBS側には操作パネルを表示しません。ソースの幅・高さは、たとえば1280×720に設定します。

**背景を透過するには：** ChibiRigKitの「背景の種類」を「単色」にし、背景色を緑の **RGB `0, 255, 0`（`#00FF00`）** にします。OBSで対象のブラウザソースを右クリック →「フィルタ」→ エフェクトフィルタの「＋」→「クロマキー」を追加してください。色キーの種類は初期設定の「緑」のままで、通常は数値を調整せずに緑背景を透過できます。輪郭の見え方に合わせて、必要な場合だけ微調整してください。

**余白を調整するには：** 同じフィルタ画面で「クロップ／パッド」を追加し、「相対」にチェックを入れたまま、左・上・右・下を調整します。正の値で余白を切り取り、負の値で余白を追加できます。

OBS公式の説明：[クロマキー](https://obsproject.com/kb/chroma-key-filter)・[クロップ／パッド](https://obsproject.com/kb/crop-pad-filter)。

操作画面で変えた背景・動きの倍率・顔配置・髪の設定・出力範囲と、読み込んだモーションの再生をOBS側へ反映します。OBSを後から開いても最新の状態を受け取ります。共有中の状態はサーバーのメモリだけに置き、サーバー終了時に消えます。設定を残したい場合は、動きのJSONや完成品として保存してください。

カメラ・音声の追従も、完成品の `START_SERVER` で起動して共有できます。完成品ZIPには追跡Worker・SDK・顔モデルと必要なライセンス表記を同梱します。SDK・モデルが不足している場合は「追従開始」でダウンロードし、ハッシュを検証して保存します。この取得時だけインターネット接続が必要で、準備後はオフラインで使えます。ChibiRigKitの `npm run player` でも同じ操作URLとOBS用URLを使えます。OBSへ共有するのは設定と動きの数値で、生のカメラ映像・音声・機器名・デバイスIDは送りません。

**VB-CABLEで口パクするには：** 音を出すアプリの出力先を「CABLE Input」、ChibiRigKitの「入力」を「マイクで口パク」、マイクを「CABLE Output」にして「追従開始」を押します。入力音量メーターとdB表示で音が届いているか確認できます。エコー除去・ノイズ抑制・自動音量調整は使わず、左右のチャンネルを個別に解析します。入力音量が「無音とみなす音量」以下なら、その値を下げるか「音声の口パク感度」を調整してください。取り込んだ音をスピーカーへ再生する機能ではありません。

カメラ・音声を使う操作画面は開いたままにしてください。OSの休止やブラウザによるページ凍結中は新しい追従値を取得できません。入力停止や通信切断で古くなった追従値は解除し、再生中のモーション、通常の動きの順で表示します。

起動したターミナルは開いたままにし、終了するときは `Ctrl+C` を押します。ポート5510が使用中の場合は、先に起動しているサーバーを停止してください。サーバーがOBSの録画・配信を開始することはありません。
